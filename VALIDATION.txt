CAUSE
The V1.0.0 source relied on implicit framework usings for System.IO. In the user's WPF build environment those IO types were not imported, creating 61 compile errors and several cascading type errors. V1.0.1 imports System.IO explicitly in every affected source file.

The current build environment does not contain the Windows .NET SDK, WPF runtime, or Microsoft Word, so native Windows compilation and COM pagination cannot be executed here. Run BUILD_AND_RUN.bat on Windows for the final native compile/runtime test.
